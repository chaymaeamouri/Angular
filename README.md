# Angular Cours & Pratiques - 5Gi

Dépôt officiel des pratiques et travaux réalisés lors des séances de cours Angular (Filière 5Gi).

## 📚 Sommaire des Séances

- **Séance 1 :** Découverte d'Angular Standalone & Création des composants autonomes (`Header`, `Footer`, `Home`, `About`).
- **Séance 2 :** Data Binding (Interpolation, Property Binding, Event Binding) et directives de contrôle de flux (`@for`, `@empty`, `@if`) dans l'application TaskFlow.
- **Séance 3 :** Gestion réactive de l'état avec les **Signals Angular** (`signal`, `computed`, `update`, `set`) et tests unitaires avec Vitest.

---

## 🚀 Démarrage du projet

```bash
# Installation des dépendances
npm install

# Démarrer le serveur de développement local
npm start
# ou
npx ng serve

# Lancer les tests unitaires
npm test
```

L'application est accessible sur `http://localhost:4200/`.
